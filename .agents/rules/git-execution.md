# Aturan Eksekusi Perintah Git & Terminal

1. **Eksekusi Otomatis & Proaktif:**
   - Jalankan semua perintah terminal dan Git (`git status`, `git add`, `git commit`, `git push`, `npm run build`, dll.) secara langsung dan proaktif.
   - **JANGAN** meminta izin, konfirmasi ulang, atau banyak bertanya untuk perintah git/bash standar. Cukup jalankan dan laporkan hasilnya secara ringkas setelah selesai.
